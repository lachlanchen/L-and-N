# L-and-N

**مدرّب نطق هادئ وشفاف يساعد على سماع L وN وإنتاجهما.**

[افتح تطبيق PWA](https://l-and-n.lazying.art) · [ملاحظات البحث](../docs/research/pronunciation-assessment.md) · [خريطة الدرس الأصلي](../docs/source-lesson.md)

يحوّل L-and-N الفرق الصوتي الصعب إلى دورة تدريب قصيرة: شاهد الحرف أو الرمز الصيني داخل الكلمة، واستمع إلى نموذج مسجّل، وراقب الإشارة، وسجّل صوتك، ثم اقرأ نتيجة موضحة. يعمل المنهج نفسه كتطبيق PWA قابل للتثبيت وتطبيق Android وتطبيق iPhone/iPad وتمرين صغير على watchOS.

![شاشة التدريب](../docs/images/pwa-practice.png)

## ماذا يقدم

- عشرون كلمة إنجليزية ضمن عشرة أزواج دنيا، إضافة إلى تمارين أصلية للماندرين والكانتونية.
- إبراز الحرف أو الرمز المستهدف وشرح بسيط لموضع اللسان ومسار الهواء.
- أصوات GPT-SoVITS الإنجليزية والأصوات الصينية الأصلية مضمّنة، فلا يحتاج الاستماع إلى خدمة TTS حية.
- يعرض موجة حية وطيف بداية الصوت لرؤية الصمت والتشبع والتوقيت، وليس كمؤشر زخرفي يدّعي تحديد «الصحة».
- يوضح نموذج فم ثلاثي الأبعاد تدفق الهواء الجانبي مع L والأنفي مع N. إنه نموذج للحركة المطلوبة ولا يدّعي استعادة لسان المتعلم الحقيقي من الميكروفون.
- تبقى المحاولات والمعايرة الشخصية الحذرة على الجهاز، وتُقيّم نغمة الصينية مستقلة عن نوع الصامت.

## نتيجة يمكن فحص أدلتها

يحدد المحلل المحلي بداية الصوت المجهور ويفحص جودة التسجيل، ثم يجمع طاقة الأنفية منخفضة التردد، ومقياساً تقريبياً من نوع A1–P0، والمسافة التقريبية بين F1 وF2، وميل الطيف، والاستمرارية، والتعرف على الكلمة المطلوبة، وتباين الزوج الأدنى. تختلف الملفات المرجعية بحسب اللغة، ولا تتغير القاعدة الشخصية إلا بحذر بعد عدة تسجيلات جيدة. تخفض الأدلة الضعيفة أو المتعارضة الثقة وتطلب إعادة المحاولة.

هذه مساعدة تدريبية وليست تشخيصاً أو حكماً على اللهجة أو قياساً معتمداً. تبين الموجة التوقيت والتشبع لكنها لا تثبت أي صامت، كما لا يمكن استنتاج موضع وحيد للسان من الصوت وحده. يشرح [تقرير البحث](../docs/research/pronunciation-assessment.md) المنهج وحدوده ومصادر L/N وGOP/CTC والنغمات والتغذية الراجعة البصرية وعكس النطق.

## الخصوصية وخدمات الكلام

تعمل السمات الصوتية والنتائج والتقدم والمعايرة محلياً. على iOS، يزوّد مسار واحد من محرك الصوت الأصلي شكل الموجة والتحليل الصوتي المحلي والتعرف على الكلام في النظام معاً؛ فلا يتنافس التطبيق مع نفسه على الميكروفون. تحاول نسخة PWA المستضافة عادةً استخدام ميزة التعرف المتوافقة في المتصفح أولاً، وقد يعالج المتصفح أو المنصة ذلك عبر خدمته الخاصة. على ويب iPhone وiPad يسجل التطبيق مساراً واحداً فقط حتى لا يتنافس شكل الموجة والمسجل على الميكروفون، ثم يفرغ المقطع القصير نفسه بعد الإيقاف. إذا كان تعرف المتصفح غير متاح أو فشل أو لم يُرجع نصاً، فقد تُرسل المحاولة مؤقتاً عبر بوابة محدودة المعدل من الأصل نفسه إلى خدمة Whisper الخاصة. لا تقبل البوابة إلا مسار التفريغ الدقيق من هذا الأصل، وتحد الحجم والتزامن، ولا تسجل الصوت أو تخزنه، وتعيد `Cache-Control: no-store`. إذا لم يتوفر تفريغ يبقى شكل الموجة ظاهراً، لكن لا تُعرض نتيجة ولا تُحفظ.

لا يحصل المتصفح على بيانات اعتماد LazyEdge ولا يتصل مباشرة بالنموذج الخاص. كل الأمثلة ملفات ثابتة أُنشئت وفُحص وضوحها وقت الإصدار.

## البناء والاختبار

يلزم Node.js 22+ وnpm، وAndroid Studio/JDK 21 لأندرويد، وXcode مع XcodeGen لمنصات Apple.

```bash
npm install
npm run check
npm run dev
npm run cap:sync
cd android && ./gradlew testDebugUnitTest assembleDebug
cd ../watch && xcodegen generate && xcodebuild -project LAndNWatch.xcodeproj -scheme LAndNWatch -sdk watchsimulator build
```

ينشئ Capacitor حزم الويب الأصلية من `dist/`. تطبيق الساعة هدف SwiftUI مستقل وصغير عمداً. لا تُضمّن الأسرار أو حالة التشغيل؛ يقرأ [مصدر البوابة](../ops/landn_gateway.py) رمزاً محدود الصلاحية من ملف محمي.

## المنهج والأدلة

يتبع أول قسم إنجليزي تسلسل الشرح النطقي والأزواج الدنيا في درس Pronunciation Snippets [“The Difference Between L & N”](https://youtu.be/78RQW1Kq_3A). يحتوي المستودع على إعادة صياغة مرتبطة بالتوقيت ولا يعيد توزيع الفيديو أو الصوت أو النص الكامل. تمارين الماندرين والكانتونية إضافات أصلية. تدريب الكانتونية اختياري بوضوح: لا يوصف اختلاف /n/→[l] الشائع في هونغ كونغ بأنه عيب أو كلام «كسول».

لا توجد بعد مجموعة كبيرة مقيّمة من الخبراء وعبر أجهزة متعددة للتحقق من الأنواع اللغوية الثلاثة. يتطلب ادعاء دقة إنتاجية نشر الدقة والاسترجاع على بيانات محجوبة، وخطأ المعايرة، والنتائج حسب المنطقة والجهاز، ونسبة امتناع النظام عن التقييم. نرحب ببروتوكولات بيانات بموافقة، ونماذج CTC/GOP على مستوى الفونيم، ومراجعة سهولة الوصول.

## بنية المشروع

- `src/` — المنهج والتحليل الصوتي والتقييم القابل للشرح وعرض الإشارة والنموذج ثلاثي الأبعاد.
- `public/audio/models/` — نماذج تدريب مضمّنة ومفحوصة الوضوح.
- `android/` و`ios/` و`watch/` — الأغلفة الأصلية وتطبيق الساعة SwiftUI.
- `ops/` — بوابة Whisper صغيرة بلا تبعيات واختباراتها.
- `docs/` — البحث ومصدر الدرس وأدلة المحاكيات.
